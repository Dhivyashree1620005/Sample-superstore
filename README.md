# Superstore Data Cleaning & Analysis

## 📌 Project Overview

This project focuses on **cleaning, validating, transforming, and analyzing Superstore sales data using Microsoft Excel**. The dataset was prepared for analysis by validating data quality, formatting date fields, creating derived fields, and organizing the data for reporting and dashboard development.

## 🎯 Objectives

* Clean and validate the Superstore sales dataset
* Check for duplicate records and missing values
* Standardize and validate date and numerical fields
* Perform text and data transformations
* Create derived fields for analysis
* Analyze sales, quantity, and profit performance
* Prepare the dataset for charts, KPIs, and reporting
* Develop an Excel-based analytical workbook

## 🧹 Data Cleaning & Preparation

The following data preparation activities were performed:

* Checked the dataset for duplicate records
* Validated Order IDs and Customer IDs
* Checked for missing values
* Reviewed Order Date and Ship Date fields
* Standardized date formats
* Validated numerical fields such as Sales, Quantity, Discount, and Profit
* Created month, day, and weekday fields for analysis
* Prepared categorical fields such as Segment, Region, Category, and Sub-Category
* Organized the dataset for analysis and visualization

## 📊 Analysis

## 📈 Key Results

The Superstore dataset contains:

* **Total Records:** 9,994
* **Unique Orders:** 5,009
* **Unique Customers:** 793
* **Total Sales:** $2,297,200.86
* **Total Profit:** $286,397.02
* **Total Quantity Sold:** 37,873
* **Data Period:** 2014–2017

### Category Performance

* **Technology** generated the highest sales among the three main categories.
* **Furniture** generated the second-highest sales.
* **Office Supplies** also contributed significantly to overall sales.

### Customer Segment Performance

* **Consumer** was the highest-performing customer segment by sales.
* **Corporate** was the second-highest-performing segment.
* **Home Office** contributed the remaining sales.
